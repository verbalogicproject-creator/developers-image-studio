Separation of Concerns

Detailed breakdown of the Translation and Execution layers.

Translation Layer (Antigravity Skill)

The LLM operates strictly as a semantic router. It does not touch the database or perform mathematical retrieval. It listens for natural language intents, formats the data, and invokes the deterministic CLI.

  • Interprets ambiguous user intents ("Where were we?").
  • Formats session summaries into clean Markdown.
  • Executes strict shell commands to interface with the OS.

Execution Layer (Memory OS)

A deterministic Node.js environment handling file indexing, cron automation, binary BLOB storage in SQLite, and pure JS Float32 Cosine Similarity calculations.

  • Provides an interactive TUI (menus, prompts) for human use.
  • Accepts argument flags for headless Agent use.
  • Manages `node-cron` jobs for automated daily ingestion.

Payload: Build Memory Engine from Scratch

Pass this to Antigravity to build the backend SQLite/Float32 retrieval system using the reference manual specifications.

You are an elite TypeScript and Next.js architect operating within a Termux Android environment. I need you to build a local, highly optimized Project Memory & Context System for our AI orchestration framework. 

This system will ingest local project files (code, markdown, and `.ctx` diagrams) and use Google's `gemini-embedding-2` model to create a searchable vector store.

**Critical Requirements & Architecture:**

1. **Termux-Safe Storage & Compute (NO VSS EXTENSIONS):** - Store file metadata, text chunks, and embedding vectors directly in `sqlite3`.
   - Embeddings must be packed into binary BLOBs using `Buffer.from(vector.buffer)`.
   - Implement a pure JavaScript cosine similarity function (`vector_math.ts`) that loops over `Float32Array` buffers to compute distances in-memory.

2. **Database Schema Setup (`db.ts`):**
   - Table `files` (id, filepath, content_hash, mtime).
   - Table `chunks` (id, file_id, chunk_index, content, symbol_name, heading, embedding BLOB, created_at).
   - Table `relations` (GraphRAG edges for .ctx files).
   - Experiential memory table for user notes.

3. **API Rules for `gemini-embedding-2`:**
   - **Ingestion (Asymmetric Document):** Send text formatted exactly as: `title: {filename} | text: {chunk_content}`.
   - **Retrieval (Asymmetric Query):** Send user queries formatted exactly as: `task: search result | query: {user_query}`.

4. **Semantic Chunkers:**
   - Build a `code_chunker.ts` that splits by top-level AST symbols (functions, interfaces).
   - Build a `ctx_chunker.ts` that extracts `@relation` tags for GraphRAG topologies.

Please scaffold `db.ts`, `vector_math.ts`, `ingester.ts`, and `retriever.ts` ensuring clean separation of concerns and robust Termux execution. Apply Reciprocal Rank Fusion (RRF) in the retriever to blend exact FTS5 text matches with the Float32 cosine scores.

Future Upgrades & Enhancements

A prioritized roadmap to evolve the Memory Engine and Agentic Loop.

Core Engine

  • Cross-Modal Search: Ingest base64 screenshots into the database. Search code by providing an image, leveraging the multimodality of `gemini-embedding-2`.
  • AST Dependency Graphing: Automatically infer GraphRAG `.ctx` relations by mapping TypeScript `import` and `export` statements during ingestion.
  • Memory Decay: Implement a time-decay function (Elo rating for memories) that slowly deprecates outdated session handoffs unless explicitly pinned.

Agentic Loop

  • Proactive Context Injection: Antigravity automatically queries the engine in the background before answering, removing the need for manual `/memory-engine` calls.
  • Disambiguation Flow: If a memory search returns low-confidence matches (< 0.6 cosine), the agent prompts the user to clarify before proceeding.
  • Git Commit Summaries: Add a skill intent where Antigravity reads `git diff`, logs the structural changes to memory, and writes the commit message.

Dashboard & UX

  • Visual GraphRAG Explorer: Integrate `D3.js` or `vis-network` to render a living, interactive 3D node map of all `.ctx` architectural relations.
  • WebSocket Sync: Connect the HTML dashboard to a local Node WebSocket server so it updates live as Antigravity executes tasks in the CLI.
  • Theme Engine: Add a robust CSS variable system to toggle between Deep Obsidian (Current), Tokyo Night, and High-Contrast Light modes.
